# Application garden tracker

## Détails application

J'ai crée cette application pour suivre les data de ma box de culture indoor.

Dans un premier je vais rentrer les données (hygrométrie, température dans la box, temperature exterieur, ph de la soupe d'engrais, EC, ...) à la main, pour par la suite mettre en place un systeme de capteurs reliés à un raspberry et un écran digital.
Je fais ça pour comparé l'évolution de mes données en fonction de mes sessions de culture, pour ensuite pouvoir faire des réglages dans le but d'améliorer le rendement et la qualité de mes fleurs.
Vu que je n'ai pas codé depuis longtemps je me fais aider par l'ia (les modèles gratuit), je relis ensuite le code, deja pour le comprendre et ensuite pour me remettre à jour.
Je vais tout faire pour tenir ce projet jusqu'a son termes malgré mes difficultés personnels et peut être qu'un employeur verra ce projet et tentera  le coup de me donner une chance.
